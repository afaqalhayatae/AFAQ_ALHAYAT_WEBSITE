# Project Glossary

## Purpose

This glossary defines the standard terms used throughout the AFAQ Alhayat Enterprise Knowledge Base to ensure consistency across business, design, development, marketing, and operations.

---

# Business Terms

## Lead

A potential customer who has shown interest in one or more company services.

## Customer

A person or organization that has booked or purchased a service.

## Booking

A confirmed or pending service request submitted through the platform.

## Service

Any maintenance, cleaning, pest control, or related solution offered by AFAQ Alhayat.

---

# Technical Terms

## Frontend

The user-facing part of the website and application.

## Backend

The server-side logic, APIs, and business processes.

## Database

The system used to store and manage application data.

## API

Application Programming Interface used for communication between systems.

## Authentication

The process of verifying a user's identity.

## Authorization

The process of determining what a user is allowed to access.

---

# SEO Terms

## Keyword

A search phrase used by customers in search engines.

## Local SEO

Optimization techniques that improve visibility in location-based search results.

## Schema Markup

Structured data that helps search engines better understand website content.

## Meta Title

The title displayed in search engine results.

## Meta Description

The short description displayed below the page title in search results.

---

# UI / UX Terms

## Responsive Design

A design approach that adapts to different screen sizes and devices.

## Accessibility

Practices that ensure the platform can be used by all users, including those with disabilities.

---

# AI Terms

## Knowledge Base

The complete collection of documentation used as the project's single source of truth.

## Claude

The AI assistant responsible for understanding and implementing the project based on the documentation.

## Prompt

A structured instruction provided to an AI assistant to perform a specific task.

---

# Documentation Rules

- Use consistent terminology across all documents.
- Update this glossary whenever new project-specific terms are introduced.
- Refer to these definitions in all future documentation.
