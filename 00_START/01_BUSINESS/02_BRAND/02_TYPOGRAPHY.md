# Typography

## Purpose

This document defines the official typography system for the AFAQ Alhayat brand.

---

# Primary Font

Name

Cairo

Usage

- Arabic Headings
- Arabic Body Text
- Buttons
- Navigation
- Forms

Reason

Excellent readability and professional appearance.

---

# Secondary Font

Name

Inter

Usage

- English Headings
- English Body Text
- Dashboard
- Tables
- Forms

Reason

Modern, clean, and optimized for digital interfaces.

# Typography Rules

- Use Cairo for all Arabic content.
- Use Inter for all English content.
- Maintain consistent spacing between headings and paragraphs.
- Avoid using more than two font families.
- Ensure readability on mobile, tablet, and desktop devices.
