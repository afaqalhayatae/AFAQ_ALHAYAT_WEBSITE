# Iconography

## Purpose

This document defines the official icon style for the AFAQ Alhayat brand across the website, dashboards, mobile interfaces, and marketing materials.

---

# Icon Style

The official icon style should be:

- Simple
- Modern
- Clean
- Professional
- Minimal
- Easy to recognize

---

# Recommended Icon Library

Primary Library

- Lucide React

Alternative Libraries

- Heroicons
- Font Awesome (Limited Use)

# Usage Rules

Icons should:

- Always match the brand colors.
- Be visually consistent.
- Have equal spacing.
- Support accessibility.
- Never replace important text labels.
