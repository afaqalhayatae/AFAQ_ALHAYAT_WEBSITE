# Purpose

This document defines all reusable UI components used on the Homepage. Every component should be designed once and reused across the platform to ensure consistency, maintainability, and scalability.

# Component Naming Convention

Every reusable component should have a unique identifier beginning with:

CMP-

Example:

CMP-001

CMP-002

CMP-003

---

# Development Notes

- Components should remain independent.
- Components should support responsive layouts.
- Components should follow the UI/UX Standard.
- Components should comply with Accessibility and SEO Standards.
