# Service Glossary

## Purpose

Shared terminology used across service-knowledge documents, so the same term means the same thing everywhere. Terms below are already in use in migrated content (see the Pest Control package and business-goal documents) and are defined here rather than re-explained per document.

---

# Terms

| Term | Definition |
|---|---|
| AMC | Annual Maintenance Contract — a recurring service agreement, referenced in `01_BUSINESS/BUSINESS_GOALS.md`. |
| SOP | Standard Operating Procedure — a documented, repeatable process step, owned by `05_OPERATIONS/SOP/`. |
| PPE | Personal Protective Equipment — required for technicians per each service's Safety document. |
| ULV Fogging | Ultra-Low Volume fogging — a pest-control treatment method using fine mist application. |
| CSAT | Customer Satisfaction score — a cross-service KPI, see `SERVICE_KPIS.md`. |
| NAP | Name, Address, Phone — the local-SEO consistency triad, owned by `02_BRAND/LOCAL_SEO_PROFILE.md`. |
| Service Package | The complete set of documents for one service, following `99_STANDARDS/SERVICE_TEMPLATE.md`. |
| Canonical | The single approved source for a fact, as opposed to a draft or superseded copy — see `SYSTEM_ARCHITECTURE.md` Sec. 6–7. |
