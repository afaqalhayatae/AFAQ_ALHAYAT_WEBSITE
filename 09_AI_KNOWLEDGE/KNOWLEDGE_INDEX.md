# Knowledge Index

## Purpose

A single map of which domain owns which fact type, so an AI system (or a human) never has to guess where a fact lives. Mirrors `SYSTEM_ARCHITECTURE.md` Sec. 6, the source-of-truth registry, kept here for AI-facing retrieval convenience.
