# Naming Conventions

---

# Purpose

This document defines the official naming conventions for the AFAQ Alhayat Enterprise Platform.

Consistent naming improves readability, maintainability, automation, and AI understanding.

---

# General Rules

- Use English for all file and folder names.
- Use UPPER_SNAKE_CASE for folders.
- Use UPPER_SNAKE_CASE for documentation files.
- Avoid spaces.
- Use underscores (_) instead of spaces.
- Use descriptive names.
- Keep names concise.
