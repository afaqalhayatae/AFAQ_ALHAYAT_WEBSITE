# Accessibility Standard

## Document Information

- Project: AFAQ Alhayat Enterprise Knowledge
- Standard: Accessibility
- Version: 1.0
- Status: Active
- Applies To: Website, Customer Portal, Admin Dashboard

---

# Purpose

This is the project-wide mandate that accessibility is a requirement, not optional polish, across every customer-facing and internal digital surface. The detailed implementation rules already exist and are approved at [`12_DESIGN_SYSTEM/ACCESSIBILITY.md`](../12_DESIGN_SYSTEM/ACCESSIBILITY.md) (Arabic) — this document does not duplicate that content; it establishes the requirement and points to it, per the Single Source of Truth rule.

---

# Mandate

- Target standard: **WCAG 2.2 Level AA**, as already established in `12_DESIGN_SYSTEM/ACCESSIBILITY.md`.
- Full bilingual support: Arabic (RTL) and English (LTR), per `PROJECT_MANIFEST.md`'s bilingual-by-design principle.
- No page, component, or document ships without meeting the detailed rules in `12_DESIGN_SYSTEM/ACCESSIBILITY.md`: text contrast and sizing, color-independent status indication, full keyboard navigation, visible focus states, alt text on meaningful images, labeled and error-clear forms, touch-appropriate button sizing, and reduced-motion support.

---

# Ownership

- `12_DESIGN_SYSTEM/ACCESSIBILITY.md` owns the detailed implementation rules.
- `99_STANDARDS/QUALITY_CHECKLIST.md` should gate releases against this standard once formally adopted as a release gate.
- This document owns only the project-wide requirement that the above must be followed.
