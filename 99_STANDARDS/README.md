# Standards

## Purpose

This folder is the single root for project-wide rules and reusable templates, per `SYSTEM_ARCHITECTURE.md` Sec. 5 and Sec. 7 ("Global standards live only under root `99_STANDARDS`"). No other folder may host a project-wide standard; page- or service-scoped documents may only reference these.

---

# Documents

| Document | Governs |
|---|---|
| `PROJECT_STANDARDS.md` | Core documentation and quality principles for the whole project. |
| `DOCUMENTATION_STANDARD.md` | How every document must be structured and written. |
| `NAMING_CONVENTIONS.md` | File, folder, ID, and code naming rules. |
| `SERVICE_TEMPLATE.md` | The required shape of a service-knowledge package. |
| `UI_UX_STANDARD.md` | Interface and experience rules for the website and portals. |
| `SEO_STANDARD.md` | Search-engine optimization rules. |
| `AI_GEO_STANDARD.md` | AI/Generative-Engine-Optimization rules. |
| `ACCESSIBILITY_STANDARD.md` | Accessibility requirements (currently empty — content not yet authored). |
| `PERFORMANCE_STANDARD.md` | Site and system performance requirements. |
| `SECURITY_STANDARD.md` | Security baseline for the website, digital systems, and data handling. |
| `QUALITY_CHECKLIST.md` | Pre-publish / pre-release quality gate. |

---

# Rule

If a rule applies to more than one page, service, or system, it belongs here — not duplicated inside the thing it governs.
