# SEO Standard

## Document Information

- Project: AFAQ Alhayat Enterprise Knowledge
- Standard: SEO
- Version: 1.0
- Status: Active
- Applies To: All Public Website Pages

---

# Purpose

This standard defines the Search Engine Optimization (SEO) requirements that every public page within the AFAQ Alhayat platform must follow.

The objective is to maximize visibility, improve search rankings, increase qualified traffic, and create a strong technical foundation for long-term organic growth.

---

# SEO Principles

Every page must:

- Serve a clear user intent.
- Provide original and valuable content.
- Be easy to crawl.
- Be easy to index.
- Be technically optimized.
- Support future scalability.

---

# Page Structure

Every page should include:

- One H1 heading only.
- Logical H2–H4 hierarchy.
- Descriptive page title.
- Unique meta description.
- Canonical URL.
- Breadcrumbs where applicable.

---

# Content Standards

Content must be:

- Original.
- Helpful.
- Accurate.
- Easy to read.
- Human-first.
- Updated when necessary.

Avoid:

- Keyword stuffing.
- Duplicate content.
- Thin content.
- Hidden text.

---

# Technical SEO

Every page must support:

- HTTPS
- XML Sitemap
- Robots.txt
- Canonical Tags
- Structured Data
- Open Graph Metadata
- Twitter Cards
- Mobile Friendly Design
- Fast Loading
- Clean URLs

---

# Internal Linking

Internal links should:

- Connect related pages.
- Support user navigation.
- Strengthen topical authority.
- Avoid orphan pages.

---

# Image Optimization

All images should:

- Use descriptive filenames.
- Include meaningful Alt Text.
- Be optimized for the web.
- Prefer WebP format.
- Use lazy loading where appropriate.

---

# Local SEO

Every local service page should include:

- Business Name
- Address
- Phone Number
- Service Areas
- Google Maps
- LocalBusiness Schema

---

# Structured Data

Supported schemas include:

- Organization
- LocalBusiness
- Service
- FAQ
- Breadcrumb
- WebSite
- Article
- Review

---

# Performance Targets

Minimum goals:

- Lighthouse Score: 95+
- Core Web Vitals: Pass
- Fast Largest Contentful Paint (LCP)
- Low Cumulative Layout Shift (CLS)
- Excellent Interaction to Next Paint (INP)

---

# Success Metrics

Measure:

- Organic Traffic
- Search Rankings
- Click Through Rate (CTR)
- Indexed Pages
- Conversion Rate
- Bounce Rate
- Average Engagement Time

---

# Standard Compliance

All website pages must comply with this SEO Standard unless a documented exception is approved.
