# SEO Standard

## Document Information

- Project: AFAQ Alhayat Enterprise Knowledge
- Standard: SEO
- Version: 1.0
- Status: Active
- Applies To: All Public Website Pages

---

# Purpose

This standard defines the Search Engine Optimization (SEO) requirements that every public page within the AFAQ Alhayat platform must follow.

The objective is to maximize visibility, improve search rankings, increase qualified traffic, and create a strong technical foundation for long-term organic growth.

---

# SEO Principles

Every page must:

- Serve a clear user intent.
- Provide original and valuable content.
- Be easy to crawl.
- Be easy to index.
- Be technically optimized.
- Support future scalability.

---

# Page Structure

Every page should include:

- One H1 heading only.
- Logical H2–H4 hierarchy.
- Descriptive page title.
- Unique meta description.
- Canonical URL.
- Breadcrumbs where applicable.

---

# Content Standards

Content must be:

- Original.
- Helpful.
- Accurate.
- Easy to read.
- Human-first.
- Updated when necessary.

Avoid:

- Keyword stuffing.
- Duplicate content.
- Thin content.
- Hidden text.

---

# Technical SEO

Every page must support:

- HTTPS
- XML Sitemap
- Robots.txt
- Canonical Tags
- Structured Data
- Open Graph Metadata
- Twitter Cards
- Mobile Friendly Design
- Fast Loading
- Clean URLs

---

# Internal Linking

Internal links should:

- Connect related pages.
- Support user navigation.
- Strengthen topical authority.
- Avoid orphan pages.

---

# Image Optimization

All images should:

- Use descriptive filenames.
- Include meaningful Alt Text.
- Be optimized for the web.
- Prefer WebP format.
- Use lazy loading where appropriate.

---

# Local SEO

A local service page may be created only for a location and service combination
approved in `03_MARKET/SERVICE_AREAS.md`.

Publish only verified fields appropriate to the real business model:

- Approved business or trading name
- Verified contact method
- Approved service-area relationship
- Physical address and map link only when the location represents a genuine,
  customer-facing or otherwise eligible business location
- Structured data that accurately reflects the entity and page

Do not create a fictional branch, address, map listing, or `LocalBusiness`
entity for every service area. Service-area businesses must follow current
search-engine eligibility rules and owner-approved business records.

---

# Structured Data

Supported schemas include:

- Organization
- LocalBusiness
- Service
- FAQ
- Breadcrumb
- WebSite
- Article
- Review

---

# Performance Targets

Minimum goals:

- Lighthouse Score: 95+
- Core Web Vitals: Pass
- Fast Largest Contentful Paint (LCP)
- Low Cumulative Layout Shift (CLS)
- Excellent Interaction to Next Paint (INP)

---

# Success Metrics

Measure:

- Organic Traffic
- Search Rankings
- Click Through Rate (CTR)
- Indexed Pages
- Conversion Rate
- Bounce Rate
- Average Engagement Time

---

# Standard Compliance

All website pages must comply with this SEO Standard unless a documented exception is approved.
