# Operations Safety

## Document Control

- Owner: Business owner
- Status: Draft
- Version: 0.1
- Publication: Blocked

## Purpose

This domain will hold cross-service health, safety, and environmental controls.
It does not authorize field work.

## Approval Gate

Every control requires owner approval and, where applicable, evidence from the
licensed external provider, manufacturer, safety data sheet, insurer, or
competent authority. Missing evidence must be recorded as `Owner Input
Required`; it must never be inferred.
