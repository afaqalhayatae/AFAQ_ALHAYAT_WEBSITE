# Brand Colors

## Purpose

This document defines the official color palette for the AFAQ Alhayat brand to ensure consistency across the website, mobile applications, marketing materials, and printed assets.

---

# Primary Color

Name: Deep Blue

HEX: #0F4C81

Usage:

- Logo
- Headers
- Primary Buttons
- Navigation
- Important Elements

---

# Brand Blue

HEX: #2563EB

Usage:

- Distinct brand blue, independent from Primary Color (Deep Blue) and from the implementation-source Info color (`#0EA5E9` in `12_DESIGN_SYSTEM/COLORS.md`). Used where a separate brand-blue accent is needed.

# Color Usage Rules

- Use Deep Blue as the primary brand color.
- Use Emerald Green for positive actions and confirmations.
- Use Gold only for premium emphasis.
- Maintain strong color contrast for accessibility.
- Avoid using more than three primary colors on the same screen.
