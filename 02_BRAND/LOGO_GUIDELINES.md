# Logo Guidelines

## Purpose

This document defines the official rules for using the AFAQ Alhayat logo across digital and printed media.

---

# Logo Versions

The brand logo should have the following versions:

- Full Color Logo
- White Logo
- Black Logo
- Icon Only
- Horizontal Version
- Vertical Version

---

# Clear Space

Always leave clear space around the logo equal to the height of the letter "A" in the logo.

No text, icons, or graphics may enter this area.

---

# Minimum Size

Digital

120 px minimum width

Print

30 mm minimum width

---

# Approved Backgrounds

The logo may be used on:

- White Background
- Deep Blue Background
- Light Gray Background
- Dark Background (White Logo Only)

---

# Incorrect Usage

Do NOT:

- Stretch the logo.
- Rotate the logo.
- Change brand colors.
- Add shadows.
- Add outlines.
- Change proportions.
- Place on busy backgrounds.
- Reduce readability.

---

# Logo Placement

Preferred locations:

- Website Header
- Website Footer
- Business Cards
- Invoices
- Company Vehicles
- Employee Uniforms
- Social Media Profiles
- Marketing Materials

---

# File Formats

Store official logo files in:

- SVG
- PNG
- PDF
- AI

---

# Ownership

The AFAQ Alhayat logo is an official company asset and may only be used according to these guidelines.
