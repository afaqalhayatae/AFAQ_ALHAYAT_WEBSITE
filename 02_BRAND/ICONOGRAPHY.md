# Iconography

## Purpose

This document defines the official icon style for the AFAQ Alhayat brand across the website, dashboards, mobile interfaces, and marketing materials.

---

# Icon Style

The official icon style should be:

- Simple
- Modern
- Clean
- Professional
- Minimal
- Easy to recognize

---

# Recommended Icon Library

Primary Library

- Lucide React

Alternative Libraries

- Heroicons
- Font Awesome (Limited Use)

---

# Two Approved Icon Systems

Two separate icon systems are approved, each for a distinct purpose:

Brand Icons

- Location: `public/brand/icons/`
- Purpose: service illustrations and marketing visuals.

UI Icons

- Library: Lucide
- Purpose: interface controls only.

Brand Icons must not be used as interface controls, and UI Icons must not be used as service illustrations or marketing visuals. Each system keeps its own existing style — Brand Icons are not redrawn to match the Lucide line-icon style described above.

# Usage Rules

Icons should:

- Always match the brand colors.
- Be visually consistent.
- Have equal spacing.
- Support accessibility.
- Never replace important text labels.
